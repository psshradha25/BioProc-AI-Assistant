# BioProc AI Assistant

AI-powered downstream bioprocessing assistant built using Streamlit.

## Features

- DSP AI Chatbot
- SOP PDF Analyzer
- DSP Troubleshooting
- DSP Engineering Calculators
- Chromatogram Analysis
- Chromatogram Comparison
- Pooling Recommendation

## Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace Embeddings
- Pandas
- Matplotlib

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
